# LIGHT / TIME — 月の光は1.3秒前

62秒 / 16:9 / 1920x1080 / 30fps。Shin-MotionMakerのRemotion制作ジョブを自動生成し、完全に独自のReact/SVGシーンとオリジナルシンセ音響をセットする。

## コンセプト
NASAが説明する「月光は約1.3秒前に発した光」を実際に時間を測って見る。文字→天体→距離→実時間移動→太陽→哲学的な回収の構成。プロダクション内の数値は平均値であり、月の軌道により変化する。地球と月の大きさ・距離は演出上の模式図。

## エディトリアル
* 出典: NASA / AMNH、request.json記載。
* 画像・音楽素材は全て当作品のプログラムで生成。ストック映像・第三者音源なし。
* 声は未実装。ナレーションのないモーショングラフィックスとして完成させる。
* YouTubeへ自動アップロードしない。映像・音響の人間レビューを経て公開判断する。
